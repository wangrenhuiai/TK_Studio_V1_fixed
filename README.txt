TK Studio V1
================

Windows 运行：

1. 打开 CMD，进入本目录
2. 执行：
   python -m pip install -r requirements.txt
3. 执行：
   python main.py

如果双击 main.py 没有窗口，请不要双击，直接在 CMD 执行：
python main.py

这样如果有错误，黑色窗口会显示具体报错信息。

本版本是可运行的 PySide6 GUI 原型，包含：
- 作品列表
- 主页提取 UI
- 单作品提取 UI
- 关键词提取 UI
- 我的主页
- 下载设置
- 浏览器/登录入口
- 软件设置
- 使用教程
